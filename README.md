One line of honest software error copy for the
[Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5)
bounty on [make.fun](https://make.fun/): a single-line error message, at
most 200 characters, that tells the user the brutal truth about what went
wrong and makes them laugh on the way.

## The line (89 characters)

> Click the traffic lights again: the captcha thinks you're a robot, and frankly, so do we.

It names the real failure in plain words (the captcha flagged the user as
a robot), tells the user what to do next (click the traffic lights again),
and lands the joke on the last words — a line a team could actually ship
in an error dialog, and a user would repeat to a colleague.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, single line, 89 characters).
